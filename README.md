# Finix Hair Studio

Professional Hair Systems & Wigs Studio portal.

## 🚀 Features
- **Premium Storefront**: Advanced hair system filtering and display.
- **Customer Dashboard**: Personalized order tracking and appointment management.
- **Admin Portal**: Secure studio management, inventory tracking, and payment monitoring.
- **Payment Integration**: Razorpay Secure Checkout.

## 💻 Tech Stack
- React + Vite
- Tailwind CSS
- Framer Motion
- Lucide Icons
- Razorpay SDK

## 🛠️ Access
- **Admin Dashboard**: `/admin` (Manual URL access)
- **Customer Account**: `/account`
